# Me Likey Wine

An Astro + Tailwind itinerary site for a friends wine trip to Santa Rosa and Sonoma County.

## Pages

- Home
- Schedule
- Wineries
- Lodging
- Map
- Packing

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The site is configured for GitHub Pages with a custom domain of `melikey.wine`.
